# books-copy

## Purpose

Let a person save one passphrase-protected copy of their books and restore
it on this or any device, for backup, for moving to a new phone, or for
giving a copy to someone. The copy never contains a private key, so no one
has to manage a key.

Full requirements land when `books-copy-and-continuation` is archived
(retiring `ledger-backup`). Background references below are preserved from
the retired ledger-backup spec so archive can drop that capability without
losing the non-normative links.

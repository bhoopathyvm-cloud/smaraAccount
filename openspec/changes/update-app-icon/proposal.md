## Why

The user selected the navy-and-ivory folded S with a calculator as Smara's
app icon and requested that it replace the existing ledger icon.

## What Changes

- Apply the approved artwork to iOS, macOS, Android, Windows, and Linux launcher assets.
- Preserve the approved source and make the existing regeneration command
  reproduce the new artwork rather than the obsolete ledger drawing.

## Capabilities

### Modified Capabilities
- `app-branding`: approved S-and-calculator launcher artwork.

## Impact

Launcher images, branding source assets, and the existing icon generation
script. No app behavior or dependency changes.

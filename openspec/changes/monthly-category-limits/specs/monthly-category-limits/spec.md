# monthly-category-limits

## Purpose

Capability for monthly category limits.

## Requirements

### Requirement: Monthly Category Limits
The user SHALL optionally set a monthly spending limit per expense category. The system SHALL show progress toward that limit for the current month and indicate when spent exceeds the limit.

#### Scenario: Over limit
- **WHEN spent exceeds the category limit this month**
- **THEN** the UI shows an over-limit indication

# Smara translation glossary

Use these English glosses so every locale pack translates accounting terms
the same way. Prefer household voice (Spent / Received / Fix) over ledger
jargon in UI strings.

| Term | Gloss |
|---|---|
| account | A named place money sits (cash, card, investment) or a category |
| ledger | The signed history of what was spent and received |
| transfer | Moving money from one account to another |
| archive / hide | Stop using an account or category for new entries without deleting history |
| opening balance | Amount already in an account when you start tracking it |
| reversal | A new opposite line that undoes an old one; the old line stays |
| posting | One side of a double-entry line (implementation term; avoid in UI) |
| journal entry | One dated event in the books (implementation term; avoid in UI) |
| category | Income or expense bucket such as Groceries |
| settle | Record what actually arrived for money that was in transit |
| spent | Money out of an account |
| received | Money into an account |
| Fix | Correct a mistake by adding a reversing line plus the right one |
| pending transfer | Money still in transit between currencies or accounts |
| closeout | Transfer leftover cash out of a hidden account |
| investment holdings | Shares/funds tracked separately from cash in an investment account |
| quote | Last market price used only as an estimate, never to record a trade |
